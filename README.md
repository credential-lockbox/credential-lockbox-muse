# credential-lockbox-muse

The Muse variant of Credential Lockbox — a client-side age-encryption wizard that runs as a Muse Space, so a user can encrypt a credential to their Muse's key on their own device and send only the ciphertext.

This repository holds the Space's source: the client (React/Vite), the server actions, and the data migrations. Credential Lockbox is a project of the credential-lockbox organization: https://github.com/credential-lockbox

Status: prototype. This tree is the source of the proto-wizard-1.5 build, published so the install flow can be tested end to end. It is not yet a production release.
